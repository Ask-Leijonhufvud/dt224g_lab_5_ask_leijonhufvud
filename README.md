# DT224G - Laboration 5

## Beskrivning

Detta är/var en skoluppgift med syftet att:
> * Förstå hur JavaScript kan användas för att läsa och förändra innehållet i DOM.
> * Använda event och eventlyssnare för att skapa interaktivitet på en webbsida.
> * Läsa och hantera värden från HTML-formulär.
> * Validera användarinmatning och visa tydliga felmeddelanden.
> * Skapa och lägga till HTML-element med JavaScript.
> * Använda ```localStorage``` för att lagra information i webbläsaren.
> * Använda ```JSON.stringify()``` och ```JSON.parse()``` för att lagra och hämta strukturerad data.
> * Strukturera JavaScript-kod i mindre funktioner med tydliga ansvarsområden.
> * Använda Git och GitHub för att versionshantera programkod.

HTML- och CSS-filer, samt delar av ```main.js```, tillhandahölls av lärarna.
